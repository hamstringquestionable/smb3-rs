View

1 KB page = 64 tiles = 32 pairs. Nudge pairs/row until a tall sprite lines up into a column — the stride only affects the display, never the tile numbers a pick records.

Palette

Click a slot, then a color. Slot 0 is the backdrop — it always renders transparent, whatever it's set to.
